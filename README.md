# Draw Your Font RU

Полностью браузерный инструмент для создания русского рукописного шрифта. Пользователь печатает размеченный PDF, заполняет его от руки, фотографирует страницы и получает устанавливаемые TTF, WOFF и WOFF2. Изображения и данные проекта обрабатываются локально и не отправляются на сервер.

## Готовый рабочий цикл

1. Создание печатного A4-шаблона для русского алфавита, цифр, знаков или собственного набора.
2. Автоматическое определение страницы, поворота и четырёх угловых меток.
3. Исправление перспективы фотографии и разрезание листа на известные ячейки.
4. Автоматическое назначение `А–Я`, `а–я`, `Ё/ё`, цифр и знаков.
5. Проверка качества, ручная кисть и ластик, перемещение и масштабирование каждого глифа.
6. Автоматические метрики, индивидуальные боковые поля и ручной/автоматический кернинг.
7. Сборка, проверка и скачивание TTF, WOFF, WOFF2, CSS и общего ZIP-пакета.
8. Экспорт, импорт и локальное автосохранение проекта.

## Этап 1: универсальная разметка фотографии

Ручной резервный режим остаётся доступен для старых листов и любых произвольных фотографий:

- адаптивная компенсация теней и неравномерного освещения;
- бинаризация и морфологическая очистка;
- поиск связанных компонентов;
- объединение точек и диакритики `Ё/ё/Й/й`;
- сортировка по строкам;
- ручное объединение, разделение и удаление рамок;
- редактирование подписей и экспорт JSON.

## Этап 2: машинно-читаемый PDF-шаблон

Каждая новая страница содержит:

- четыре различные угловые метки, позволяющие определить ориентацию;
- защищённый контрольной суммой машинный код страницы;
- идентификаторы набора, сетки, номера страницы и общего количества символов;
- базовую линию, высоту строчных, линию выносных элементов и центр ячейки;
- контрольную линейку и нумерацию.

Основной русский набор содержит 88 символов и помещается на двух листах A4.

## Этап 3: настоящий шрифт

Собственный сборщик создаёт таблицы TrueType `head`, `hhea`, `maxp`, `OS/2`, `hmtx`, `cmap`, `loca`, `glyf`, `name`, `post` и `kern`. Контуры строятся из масок с сохранением внутренних отверстий. Перед скачиванием проверяются сигнатуры, таблицы, Unicode-карта и контрольные суммы.

## Этап 4: автоматический сканер и редактор

- множественная загрузка фотографий;
- повороты 0°, 90°, 180° и 270°;
- проективное выпрямление листа;
- определение набора, сетки и номера страницы;
- отчёт о пропущенных и повторных страницах;
- предупреждения о пустых, слишком маленьких, высоких или касающихся края символах;
- кисть, ластик, отмена и повтор;
- смещение и масштабирование глифа;
- индивидуальные метрики и визуальное сравнение по общей базовой линии;
- автоматические интервалы и предложения кернинга;
- ручное редактирование кернинговых пар;
- проект формата DYFR v4 с RLE-сжатием масок;
- автосохранение в браузере и перенос проекта JSON между устройствами.

## Автономный WOFF2

Runtime `fonteditor-core 2.6.3` и Google WOFF2 WebAssembly собираются в локальные файлы `vendor/woff2-codec.mjs` и `vendor/woff2.wasm`. Опубликованный GitHub Pages не обращается к CDN. Для подготовки runtime выполните:

```bash
npm install
npm run build:runtime
```

## Запуск

```bash
npm install
npm run build:runtime
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## Проверки

Детерминированные тесты алгоритмов, FontTools и Chromium:

```bash
npm run test:all
```

Полный цикл в Chromium, Firefox и WebKit:

```bash
npx playwright install chromium firefox webkit
npm run test:cross-browser
```

Автотесты охватывают:

- тени, шум, диакритику и ручные правки;
- PDF и машинный код страницы;
- все четыре поворота и перспективное искажение;
- отсутствие, повтор и объединение нескольких страниц;
- сохранение/восстановление масок и метрик;
- TTF/WOFF/WOFF2, Unicode `А/Ё`, ZIP и CSS;
- независимый разбор созданного шрифта библиотекой FontTools;
- установку результата через браузерный `FontFace`;
- локальный WOFF2 runtime без внешнего CDN.

## Публикация

Workflow GitHub Actions сначала запускает детерминированные тесты и отдельный полный цикл в Chromium, Firefox и WebKit. Только после прохождения обоих заданий он заново собирает локальный WOFF2 runtime и публикует статический сайт в GitHub Pages.
