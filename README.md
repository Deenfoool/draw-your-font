# Draw Your Font RU

Браузерный инструмент для создания русского рукописного шрифта. Всё работает локально и публикуется как статический сайт через GitHub Pages.

## Этап 1: распознавание и разметка

- загрузка PNG/JPG/WEBP;
- компенсация теней и неравномерного освещения;
- адаптивная бинаризация и очистка штрихов;
- поиск и сортировка букв по строкам;
- сохранение точек `Ё/ё` и диакритики `Й/й`;
- ручное объединение, удаление и разделение рамок;
- русские наборы символов и ручное исправление подписей;
- экспорт разметки в JSON.

## Этап 2: русский PDF-шаблон

- генерация настоящего многостраничного PDF A4 прямо в браузере;
- основной русский набор из 88 символов полностью совпадает с порядком этапа 1;
- отдельные наборы: заглавные, строчные, все русские буквы, расширенный и пользовательский;
- обязательная поддержка `Ё/ё`;
- четыре размера сетки, включая автоматический компактный режим для расширенного набора;
- постраничное превью до скачивания;
- базовая линия, высота строчных, линия выносных элементов и центр ячейки;
- регистрационные метки по четырём углам для будущего автоматического выравнивания фотографии;
- нумерация каждой ячейки, страницы и схемы сетки;
- контрольная линейка 50 мм и инструкция печати A4 в масштабе 100%;
- PDF формируется без внешних библиотек и повторно проверяется перед скачиванием;
- фотографии и PDF не отправляются на сервер.

## Проверки

```bash
npm test
```

Команда запускает тесты обоих этапов. Они проверяют сегментацию, тени, диакритику, порядок строк, ручные операции, русские наборы, границы A4, порядок символов, количество страниц и корректность PDF `xref/startxref`.

Дополнительно интерфейс и реальный PDF проверены в Chromium. Сгенерированный файл открыт PDF-рендерером как две страницы A4 `595 × 842 pt`; визуальная проверка не выявила обрезанного текста, сломанных кириллических символов или пересечений элементов.

## Запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`.

## GitHub Pages

Workflow `.github/workflows/pages.yml` сначала запускает тесты, а затем публикует содержимое `main` через GitHub Pages.
