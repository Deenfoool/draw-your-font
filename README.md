# Draw Your Font RU

Полностью браузерный инструмент для создания русского рукописного шрифта. Фотография и разметка остаются на устройстве пользователя; сервер для обработки не нужен.

## Готовые этапы

### Этап 1. Распознавание и разметка

- загрузка PNG/JPG/WEBP;
- компенсация теней и неравномерного освещения;
- адаптивная бинаризация и очистка маски;
- поиск, объединение и сортировка символов;
- поддержка отделённых точек `Ё/ё` и `Й/й`;
- ручное объединение, разделение и удаление рамок;
- редактирование подписей и экспорт JSON.

### Этап 2. Печатный русский шаблон

- PDF A4 прямо в браузере;
- русские наборы с `Ё/ё`, цифрами и знаками;
- собственный набор символов;
- сетки 6×8, 7×7, 6×7 и 5×7;
- направляющие, регистрационные метки и контрольная линейка;
- постраничное превью и проверка структуры PDF.

### Этап 3. Настоящий шрифт

- преобразование бинарной маски каждой буквы в векторные контуры;
- настраиваемая детализация, сглаживание, высота и боковые поля;
- собственный сборщик таблиц TrueType: `head`, `hhea`, `maxp`, `OS/2`, `hmtx`, `cmap`, `loca`, `glyf`, `name`, `post`;
- Unicode cmap для русских символов, включая `Ё/ё`;
- TTF с глобальной контрольной суммой;
- WOFF с покомпонентным zlib-сжатием, когда оно поддерживается браузером;
- WOFF2 через браузерный Google WOFF2 WebAssembly;
- проверка результата через браузерный `FontFace`;
- готовый `@font-face` CSS;
- отдельные загрузки TTF/WOFF/WOFF2/CSS и общий ZIP-пакет;
- обнаружение повторяющихся и неподписанных символов.

## Запуск

Откройте проект через статический HTTP-сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Проверка

```bash
npm test
python tests/validate_generated_font.py
npm run test:browser
```

Полный набор:

```bash
npm run test:all
```

Тесты проверяют сегментацию, PDF-шаблон, векторизацию, TTF/WOFF, Unicode cmap, русские имена, контуры, ZIP, совместимость WOFF2 и полные пользовательские сценарии в Chromium.

## Зависимость WOFF2

Кодек WOFF2 загружается в браузере из закреплённой версии `fonteditor-core@2.6.3`. Адреса записаны в `src/woff2-loader.js`; фотография и контуры на CDN не отправляются, туда загружается только исполняемый код WASM.
