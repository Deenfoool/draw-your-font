# Draw Your Font RU

Версия `1.5.0`. Полностью браузерный инструмент для создания русского рукописного шрифта. Фотографии, проекты и готовые шрифты обрабатываются локально и не отправляются на сервер.

## Рабочий цикл

1. Пользователь выбирает удобный способ начала работы:
   - новый машинно-читаемый PDF-шаблон;
   - ручной режим для обычной фотографии или старого шаблона.
2. Для нового шаблона пользователь скачивает PDF, распечатывает и заполняет его.
3. Блок загрузки фотографий появляется только после успешного скачивания проверенного PDF.
4. Страницы автоматически выпрямляются и разбираются на символы.
5. Символы исправляются в редакторе, настраиваются метрики и кернинг.
6. При необходимости включается связный русский почерк.
7. Готовый шрифт экспортируется в TTF, WOFF, WOFF2, CSS и ZIP.
8. Собранный шрифт можно добавить в локальную библиотеку и позднее снова открыть его проект.

## Этап 1: фотография или шаблон

На стартовом экране два равноправных варианта расположены рядом под вопросом «Как вам удобнее создать шрифт?».

Ручной режим поддерживает:

- обычные фотографии и старые шаблоны;
- компенсацию теней и неравномерного освещения;
- бинаризацию и морфологическую очистку;
- объединение частей букв и диакритики;
- ручное объединение, разделение и удаление найденных областей;
- назначение подписей и передачу результата в редактор.

## Этап 2: машинно-читаемый PDF

Каждая страница содержит:

- четыре разные угловые метки;
- защищённый контрольной суммой код страницы;
- номер страницы, сетку и набор символов;
- базовую линию, x-height и линию нижних элементов;
- контрольную линейку и нумерацию.

Основной русский набор содержит 88 символов и помещается на двух листах A4. Блок «Загрузите все фотографии заполненных страниц» скрыт до успешного скачивания PDF.

## Этап 3: редактор глифов

- кисть и ластик;
- отмена и повтор;
- перемещение и масштабирование маски;
- индивидуальные боковые поля и ширина;
- общая базовая линия;
- ручной и автоматический кернинг;
- импорт, экспорт и автосохранение проекта DYFR.

## Этап 3.5: связный русский почерк

Раздел полностью свёрнут по умолчанию. Галочка в заголовке одновременно включает связный режим и разворачивает настройки.

Для каждой строчной буквы создаются формы `isol`, `init`, `medi` и `fina`. Итоговый шрифт содержит OpenType `GSUB` с `calt/rlig` и `GPOS` с `curs`.

Настройки формы `Сдвиг X`, `Сдвиг Y` и `Масштаб` убраны из пользовательского интерфейса. Остаются настройки реальных соединений, базовой линии и нижних элементов.

Поле «Проверка строки» многострочное. Предпросмотр:

- переносит слова на следующую строку;
- поддерживает ручные переводы строк;
- автоматически увеличивает высоту canvas;
- показывает baseline и descender для каждой строки;
- не обрезает длинный текст.

## Этап 6: базовая линия и нижние элементы

Рукописные `д`, `р`, `у`, `ф`, `щ`, `ц` используют настоящую базовую линию. Всё, что находится ниже неё, получает отрицательные координаты TrueType.

- тело буквы остаётся на строке;
- нижний элемент не поднимает весь символ;
- входные и выходные якоря не проваливаются в нижнюю зону;
- глубина нижнего элемента регулируется отдельно;
- `hhea` и `OS/2` получают достаточный отрицательный `descent`;
- нижние контуры не обрезаются в Word и браузерах.

Проверочные строки: `дрожь`, `друг`, `щука`, `цифра`, `уфимец`.

## Этап 4: сборка шрифта

Собственный сборщик создаёт TrueType-таблицы `head`, `hhea`, `maxp`, `OS/2`, `hmtx`, `cmap`, `loca`, `glyf`, `name`, `post`, `kern`, а для связного режима также `GSUB` и `GPOS`.

Перед скачиванием проверяются сигнатура, обязательные таблицы, Unicode-карта, контрольные суммы, контекстные lookup и курсивные якоря.

## Этап 8: локальная библиотека шрифтов

После успешной сборки рядом с кнопками скачивания появляется активная кнопка «Добавить в библиотеку». Одинаковый проект, семейство, начертание и режим обновляют существующую запись вместо создания дубля.

Отдельная страница `library.html` поддерживает:

- хранение TTF, WOFF, WOFF2, CSS, ZIP и проекта DYFR в IndexedDB;
- обычные и связные шрифты;
- живой предпросмотр через браузерный `FontFace`;
- общий текст предпросмотра для всех карточек;
- поиск и сортировку;
- повторное скачивание каждого формата;
- возврат сохранённого проекта в редактор;
- удаление записей;
- отображение размера библиотеки и доступной квоты;
- запрос постоянного хранения для защиты от автоматической очистки браузером;
- синхронизацию открытых вкладок через `BroadcastChannel` и событие `storage`.

Библиотека локальна для конкретного браузера и профиля. Для резервной копии важных проектов рекомендуется дополнительно скачивать проект JSON и ZIP-пакет.

## Автономные runtime

`fonteditor-core 2.6.3`, WOFF2 WebAssembly и резервный HEIC/HEIF-декодер собираются локально в `vendor`. Опубликованная версия не зависит от CDN.

```bash
npm install
npm run build:runtime
```

Сборщик:

- проверяет нумерацию частей с `0` или `1`;
- запрещает пропуски и дубликаты;
- проверяет синтаксис прямых JS-модулей;
- подключает baseline engine, UI flow, многострочный предпросмотр и библиотеку;
- печатает SHA-256 проверенных модулей.

## Запуск

```bash
npm install
npm run build:runtime
python -m http.server 8000 --bind 0.0.0.0
```

Откройте `http://localhost:8000`. В GitHub Codespaces откройте перенаправленный порт 8000.

Библиотека доступна по адресу `http://localhost:8000/library.html`.

## Проверки

```bash
python -m pip install fonttools brotli websocket-client uharfbuzz
npm run test:all
```

Полный цикл в Chromium, Firefox и WebKit:

```bash
npx playwright install chromium firefox webkit
npm run test:cross-browser
```

Автотесты охватывают:

- стартовый выбор из двух способов работы;
- скрытие сканера до успешного скачивания PDF;
- одинаковые внутренние отступы заголовков;
- свёрнутое состояние Stage 3.5;
- многострочный перенос предпросмотра;
- целостность runtime-сборки;
- PDF и машинный код страницы;
- повороты и перспективное искажение;
- резервное декодирование JPEG, PNG, WEBP и HEIC/HEIF;
- TTF, WOFF, WOFF2, ZIP и CSS;
- FontTools и HarfBuzz;
- `GSUB`, `GPOS`, `calt`, `rlig`, `curs`, `DFLT`, `cyrl`;
- отрицательный `yMin` нижних элементов;
- сохранение файлов и проекта в IndexedDB;
- отображение, поиск, предпросмотр, повторное открытие и удаление библиотечной записи;
- Chromium, Firefox и WebKit.
