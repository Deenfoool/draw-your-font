# Draw Your Font RU

Браузерная версия инструмента для превращения фотографии рукописного алфавита в шрифт. Проект работает локально в браузере и рассчитан на публикацию через GitHub Pages.

## Готово: этап 1

- загрузка PNG/JPG/WEBP и уменьшение больших фото без искажения пропорций;
- автоматический учёт неравномерного освещения и широких теней;
- нормализация контраста и адаптивная бинаризация;
- морфологическое закрытие мелких разрывов штриха;
- поиск связанных компонентов;
- объединение отделённых точек и диакритики, включая `Ё`, `ё`, `Й`, `й`;
- фильтрация шума и длинных направляющих линий;
- автоматическая сортировка символов по строкам слева направо;
- ручной выбор рамок на изображении и в списке;
- ручное объединение, удаление и точное разделение ошибочных рамок щелчком по фотографии;
- русские наборы символов с обязательной поддержкой `Ё/ё`;
- ручное исправление подписи каждого символа;
- экспорт полной разметки в JSON;
- полностью локальная обработка: фотография никуда не отправляется.

## Локальная проверка

```bash
npm test
```

Расширенная проверка интерфейса в Chromium на Linux:

```bash
npm run test:browser
```

Для неё нужны Chromium, Xvfb, Python и пакет `websocket-client`.

Автотесты проверяют:

1. распознавание штрихов при сильной тени;
2. сохранение и объединение отделённой диакритики;
3. порядок символов в нескольких строках;
4. удаление точечного шума;
5. ручное объединение, удаление и разделение рамок;
6. полный сценарий загрузки и обработки в Chromium.

## Запуск

Откройте `index.html` через любой статический HTTP-сервер. Например:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.
