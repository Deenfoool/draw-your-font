# Draw Your Font RU

Версия `1.7.0`. Браузерный редактор русского рукописного шрифта с машинно-читаемым PDF-шаблоном, ручным режимом, связными формами, личной и общей библиотеками.

Фотографии, распознавание, редактирование глифов и личная библиотека обрабатываются локально в браузере. В общую библиотеку по решению автора отправляются только готовые файлы шрифта и публичные метаданные.

## Рабочий цикл

1. Выбрать новый машинно-читаемый шаблон или ручной режим для обычной фотографии.
2. Распознать страницы и проверить сомнительные символы.
3. Исправить маски, направляющие, метрики и кернинг.
4. При необходимости включить связный русский почерк.
5. Собрать TTF, WOFF, WOFF2, CSS и ZIP.
6. Сохранить шрифт в личной библиотеке или опубликовать в общей.

## Recognition Engine 2.0

Распознавание версии `1.7.0` не использует нейросети. Для каждого глифа создаётся несколько независимых вариантов маски:

- локальный порог по оценке фона;
- Sauvola для тонких и слабых штрихов;
- Wolf для фотографий с тенями;
- глобальный Otsu;
- мягкие, обычные и строгие параметры отделения чернил.

Каждый вариант оценивается по сохранности штрихов, контрасту, количеству компонентов, касанию краёв, остаткам линий шаблона, положению относительно базовой линии и профилю ожидаемого символа. В проект попадает вариант с лучшим баллом.

### Машинный шаблон

Новый шаблон распознаётся по известной геометрии, а не как произвольный набор прямоугольников:

- четыре угловых маркера исправляют поворот и перспективу;
- машинный код восстанавливает страницу, сетку и набор символов;
- каждая ячейка вырезается по точным координатам;
- известные горизонтальные направляющие и центральная линия удаляются отдельно;
- пересекавшие направляющую штрихи восстанавливаются направленным соединением;
- `Ё`, `ё`, `Й`, `й`, знаки пунктуации и нижние элементы получают отдельные правила;
- базовая линия и нижняя зона сохраняются в координатах глифа.

Для каждого символа рассчитывается уверенность от 0 до 100 и конкретные предупреждения. После сканирования интерфейс показывает:

- надёжные глифы;
- глифы, которые стоит проверить;
- проблемные глифы;
- среднюю уверенность страницы;
- список символов для первоочередной ручной проверки.

### Ручной режим

Ручной режим также перебирает несколько классических методов бинаризации и автоматически выбирает вариант с наиболее устойчивыми строками и компонентами. Пользовательские регуляторы остаются базовыми параметрами и продолжают влиять на поиск.

Ручные операции сохраняются:

- объединение частей;
- разделение по вертикальной линии;
- удаление лишних областей;
- назначение символов;
- передача результата в редактор.

## Редактор глифов

- кисть и ластик;
- отмена и повтор;
- перемещение и масштабирование маски;
- отдельные направляющие и метрики;
- автоматические метрики и кернинг;
- импорт, экспорт и автосохранение проекта DYFR;
- настоящая базовая линия и нижние элементы `д`, `р`, `у`, `ф`, `щ`, `ц`.

## Связный русский почерк

Для строчных букв создаются формы `isol`, `init`, `medi`, `fina`. Итоговый шрифт содержит OpenType `GSUB` с `calt/rlig` и `GPOS` с `curs`.

Поле проверки поддерживает перенос слов, ручные переводы строк и отдельные baseline/descender для каждой строки.

## Моя библиотека

Личная библиотека хранится в IndexedDB конкретного браузера. В неё записываются:

- TTF;
- WOFF;
- WOFF2;
- CSS;
- ZIP;
- полный проект DYFR.

Запись можно скачать, удалить или снова открыть в редакторе. Личная библиотека не видна другим посетителям и может исчезнуть при очистке данных сайта, поэтому важные проекты нужно дополнительно экспортировать.

## Общая библиотека

Общая библиотека находится на Node.js-сервере и видна всем посетителям одного развёрнутого экземпляра сайта.

Перед публикацией автор указывает имя, описание, лицензию и подтверждает право на публикацию. Поддерживаются:

- SIL Open Font License 1.1;
- CC0 1.0;
- CC BY 4.0.

На сервер отправляются только готовые файлы и публичные метаданные. Фотографии, маски и проект DYFR не отправляются.

Сервер проверяет сигнатуры файлов, ограничивает размеры, общий объём и количество публикаций, использует атомарную запись, rate limiting, ключ владельца и закрытый административный ключ.

## Установка

```bash
npm install
npm run build:runtime
```

## Запуск с общей библиотекой

```bash
npm start
```

По умолчанию сайт доступен по адресу:

```text
http://localhost:8000/
http://localhost:8000/library.html
```

Параметры командной строки:

```bash
node server.mjs --host 127.0.0.1 --port 8000 --data-dir /srv/draw-your-font-data/public-fonts
```

Основные переменные окружения:

```text
HOST
PORT
DYFR_DATA_DIR
DYFR_TRUST_PROXY
DYFR_MAX_PUBLIC_BYTES
DYFR_MAX_PUBLIC_FONTS
DYFR_ADMIN_TOKEN
```

Статический запуск через `python -m http.server` оставляет рабочими редактор и личную библиотеку, но общая библиотека и публикация недоступны.

## Docker

```bash
export DYFR_ADMIN_TOKEN="$(openssl rand -hex 32)"
docker compose up -d --build
```

Общие шрифты сохраняются в постоянном volume. Для обычного VPS имеются примеры:

```text
deploy/nginx.conf.example
deploy/draw-your-font.service.example
.env.example
```

Папку `DYFR_DATA_DIR` необходимо включать в резервные копии.

## Проверки

```bash
python -m pip install fonttools brotli websocket-client uharfbuzz
npm run test:all
```

Кросс-браузерный прогон:

```bash
npx playwright install chromium firefox webkit
npm run test:cross-browser
```

Автотесты охватывают:

- несколько методов бинаризации;
- тени и неравномерное освещение;
- слабые и разорванные штрихи;
- удаление направляющих с восстановлением пересечений;
- верхние знаки `Ё/ё/Й/й`;
- нижние элементы русских букв;
- оценку уверенности;
- ручную сегментацию;
- исправление перспективы и восстановление страниц;
- TTF, WOFF, WOFF2, CSS и ZIP;
- FontTools, HarfBuzz, GSUB и GPOS;
- личную IndexedDB-библиотеку;
- серверную публикацию, скачивание, обновление и удаление;
- Chromium, Firefox и WebKit.
